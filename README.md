# Retail Sales, Cost & Target Performance Dashboard

**Business Intelligence | Microsoft Power BI**

## Project Overview
A two-page interactive Power BI dashboard designed to analyze retail sales performance, cost structure, gross margin, and target achievement.

The report combines sales, cost, store, category, and date information to provide an overview of business performance and support data-driven decisions.

## Dashboard Pages

### 1. Sales Performance
- Total Sales
- Total Gross Margin
- Sales Year-to-Date (YTD)
- Performance analysis across stores and categories

### 2. Cost & Target Analysis
- Total Cost
- Rent and Wages
- Target Sales
- Difference from Target
- Payroll Percentage

## Data Model
The project uses multiple data tables covering:
- Retail Sales
- Retail Cost
- Store Details
- Categories
- Date

## Tools & Techniques
- Microsoft Power BI
- Data Modeling
- Data Visualization
- KPI Reporting
- Interactive Dashboards
- Business Performance Analysis

## Project Objective
To transform retail sales and cost data into interactive reports that help monitor financial and operational performance, evaluate target achievement, and identify key business trends.
